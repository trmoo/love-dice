① 잠금화면 · 배경화면 만들기

앱을 따로 깔지 않아도 됩니다. 아이폰·안드로이드 모두 이 방법이 가장 확실합니다.

저장하는 법
· 아이폰 : 위 그림을 손가락으로 꾹 누르고 → 「사진에 추가」
· 안드로이드 : 위 그림을 꾹 누르고 → 「이미지 다운로드」
저장한 뒤 설정 → 배경화면에서 골라 주세요.

② 아이폰 잠금화면 위젯 (진짜 위젯)

무료 앱 Scriptable 하나만 깔면, 잠금화면·홈화면에 오늘 문구가 매일 저절로 바뀌며 뜹니다.

  1. App Store 에서 Scriptable 을 설치합니다. (무료)
  2. 아래 [스크립트 복사] 를 누릅니다.
  3. Scriptable 을 열고 오른쪽 위 ＋ → 붙여넣기 → 이름을 사랑의 주사위 로 저장합니다.
  4. 잠금화면을 꾹 눌러 사용자화 → 잠금화면 → 위젯 추가 → Scriptable 을 고릅니다.
  5. 위젯을 눌러 Script = 사랑의 주사위, When Interacting = Run Script 로 맞춥니다.
…
먼저 배포해 주세요. 이 파일을 그냥 열어 본 상태라 앱 주소를 알 수 없습니다. Apps Script 로 배포한 뒤 그 주소로 접속해서 이 화면을 열면 주소가 저절로 채워집니다.

③ 아이폰 단축어로 아침 알림

위젯 대신, 매일 아침 오늘 문구를 알림으로 받는 방법입니다.

  1. 단축어 앱 → 자동화 → 새로운 자동화 → 시각 → 오전 7:00 · 매일 · 즉시 실행
  2. 동작 추가 → URL 콘텐츠 가져오기 → 아래 주소를 붙여넣습니다.
  3. 동작 추가 → 사전 값 가져오기 → 키 text
  4. 동작 추가 → 알림 표시 → 위 결과를 넣습니다.
(앱을 배포하면 주소가 표시됩니다)

④ 안드로이드 위젯

안드로이드는 웹에서 바로 위젯을 만들 수 없어, 두 가지 길이 있습니다.

쉬운 길 — 배경화면

위 ①번에서 그림을 만들어 저장한 뒤, 설정 → 배경화면 → 잠금화면 에 지정하면 끝입니다. 추가 앱이 필요 없습니다.

자동으로 매일 바꾸고 싶다면

  1. Play 스토어에서 KWGT(무료) 를 설치합니다.
  2. 위젯을 하나 만들고 텍스트 항목을 넣습니다.
  3. 텍스트 수식에 아래 수식을 그대로 붙여 넣습니다. json 은 「JSON 에서 골라 오기」, .text 는 「그중 문구만」 이라는 뜻입니다. (Tasker 를 쓴다면 HTTP Request → JSON 읽기 로도 됩니다.)

사랑의 주사위란?

“끼아라, 저는 예수님을 닮고 싶어요. 어떻게 하면 되나요?”
— 1998년 4젠 대회에서 베네수엘라의 안젤리카가 물었습니다.

끼아라 루빅은 ‘사랑의 예술’에 대해 이렇게 답했습니다. “‘사랑의 예술’이란 모든 이를 사랑하는 것, 먼저 사랑하는 것, 지금 내 곁에 있는 사람을 사랑하는 것, 잘못을 용서해 주는 것, 다른 사람의 말에 귀를 기울이는 것, 서로 사랑하는 것을 말해요. 이 모든 것이 사랑의 주사위에 쓰여 있어요.”

그때부터 전 세계의 아이들은 매일 아침 주사위를 던지는 단순한 놀이를 합니다. 나온 말씀을 그날 하루 실천하며 사는 것입니다. 지금은 어린이뿐 아니라 청소년·젊은이·어른들까지 학교, 성당, 직장에서 함께 던집니다.

“그러므로 여러분은 무엇이든지 사람들이 여러분을 위해 해주기 바라는 것을 그대로 그들에게 해 주십시오!” (마태오 7장 12절, 황금률)

여섯 면의 말씀

우리나라의 사랑의 주사위

가톨릭신문(2010년 1월 20일)에 따르면, 허용 신부는 포콜라레 모임에서 성경 구절이 새겨진 종이 주사위로 묵상 주제를 고르는 것을 보고 이를 신자들을 위해 각색했습니다. 한 달여의 설문조사로 신자들이 가장 좋아하는 구절을 골라 인체에 무해한 대추나무로 가로·세로 3cm 남짓, 한 손에 쏙 들어오는 주사위를 만들었습니다. 「이웃과 하나되자」, 「항상 감사하자」 같은 문구가 새겨져 있고, 주일학교와 레지오 모임에서도 묵상 주제로 쓰입니다.

“매일 아침 남편이 출근하기 전 시간을 내 함께 주사위를 던집니다. 생활이 풍요로워진 기분이에요.”
— 김기원(56) 신자
