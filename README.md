# 💜 사랑의 주사위

포콜라레 운동의 **「사랑의 주사위」(Cube of Love)** 를 폰에서 쓸 수 있게 만든 웹앱입니다.

매일 아침 주사위를 던져 나온 말씀 한 가지를 그날 하루 실천하고,
실천한 이야기를 익명 또는 실명으로 나누며, 서로의 이야기에 **하트로 공감**합니다.
뽑은 문구는 **폰 잠금화면·배경화면·위젯**에 올려 둘 수 있습니다.

> “‘사랑의 예술’이란 모든 이를 사랑하는 것, 먼저 사랑하는 것, 지금 내 곁에 있는 사람을
> 사랑하는 것, 잘못을 용서해 주는 것, 다른 사람의 말에 귀를 기울이는 것,
> 서로 사랑하는 것을 말해요. 이 모든 것이 사랑의 주사위에 쓰여 있어요.”
> — 끼아라 루빅, 1998년 4젠 대회

## 화면

| 탭 | 하는 일 |
|---|---|
| 🎲 **주사위** | 3D 주사위를 던진다(버튼 또는 **폰 흔들기**). 나온 면의 해설을 읽고 「오늘의 실천」으로 정한다. 오늘 함께 던진 사람 수와 면별 분포를 본다. |
| 💬 **나눔** | 실천한 이야기를 **익명/실명**으로 올린다. 남의 이야기에 **하트**를 누른다. 최신순·공감순 정렬, 면별 필터, 신고, 내 글 지우기. |
| 📱 **위젯** | 내 폰 해상도에 맞춘 **잠금화면/배경화면 그림**을 만든다. 아이폰용 **Scriptable 위젯 스크립트**와 **단축어 레시피**, 안드로이드용 **KWGT/Tasker 주소**를 받는다. |
| 📖 **소개** | 사랑의 주사위의 유래, 여섯 면의 해설 원문, 우리나라의 대추나무 주사위 이야기. |

## 설치 — 구글 스프레드시트에 올리기

이 앱은 **구글 Apps Script 웹앱**입니다. 서버를 따로 빌릴 필요가 없고,
글과 하트는 **내 구글 스프레드시트**에 쌓입니다.

1. 구글 드라이브에서 **새 스프레드시트**를 하나 만듭니다. (이름은 자유, 예: `사랑의 주사위 기록`)
2. 스프레드시트 메뉴에서 **확장 프로그램 → Apps Script** 를 엽니다.
3. 왼쪽 파일 목록에서 아래 두 파일을 만들고 내용을 그대로 붙여 넣습니다.
   - `코드.gs` (또는 `Code.gs`) ← 이 폴더의 **`Code.gs`**
   - **＋ → HTML** 로 `index` 파일을 만들고 ← 이 폴더의 **`index.html`**
     *(파일 이름은 반드시 `index` 여야 합니다. 확장자 `.html` 은 자동으로 붙습니다.)*
4. 💾 저장합니다.
5. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - **다음 사용자 인증 정보로 실행** : `나`
   - **액세스 권한이 있는 사용자** : `모든 사용자`
   - **배포** → 권한 승인(처음 한 번, 「고급 → 안전하지 않음(이동)」을 눌러야 할 수 있습니다)
6. 나온 **웹 앱 URL**(`…/exec` 로 끝나는 주소)이 앱 주소입니다. 이 주소를 공유하세요.
7. 스프레드시트를 새로고침하면 위쪽에 **💜 사랑의 주사위** 메뉴가 생깁니다.
   **시트 준비하기**를 한 번 눌러 주세요. (누르지 않아도 첫 사용 때 자동으로 만들어집니다.)

> **주소를 바꾸지 않고 고치기** — 코드를 고친 뒤에는 **배포 → 배포 관리 → 연필(수정)
> → 버전: 새 버전 → 배포** 를 누르세요. 「새 배포」를 누르면 주소가 바뀝니다.

### 만들어지는 시트 3장

| 시트 | 내용 |
|---|---|
| `경험담` | 올라온 이야기 한 줄씩 (번호·시각·이름·익명·면·내용·하트 수·상태·신고 수 등) |
| `오늘의 주사위` | 사람마다 오늘 나온 면 (기기 하나 = 한 줄, 계속 덮어쓰므로 무한히 늘지 않습니다) |
| `면별 집계` | 날짜별 참여자 수와 면별 횟수 |

## 폰에 위젯 올리기

### ① 잠금화면·배경화면 그림 — **아이폰·안드로이드 공통, 앱 설치 필요 없음** (가장 쉬움)

1. 앱의 **📱 위젯** 탭 → 「잠금화면용 / 배경화면용」과 색을 고릅니다.
2. **[내 폰 크기로 만들기]** 를 누르면 내 화면 해상도에 딱 맞는 그림이 나옵니다.
3. 그림을 **손가락으로 꾹 눌러** 저장합니다.
   - 아이폰 : 「사진에 추가」
   - 안드로이드 : 「이미지 다운로드」
4. **설정 → 배경화면**에서 저장한 그림을 고릅니다.

### ② 아이폰 — 매일 저절로 바뀌는 진짜 잠금화면 위젯

무료 앱 **Scriptable** 이 필요합니다.

1. App Store 에서 **Scriptable** 설치
2. 앱의 **위젯** 탭에서 **[스크립트 복사]** (내 주소·기기 번호가 이미 채워진 완성본입니다)
3. Scriptable → **＋** → 붙여넣기 → 이름 `사랑의 주사위` 로 저장
4. 잠금화면 꾹 누르기 → **사용자화 → 잠금화면 → 위젯 추가 → Scriptable**
5. 위젯을 눌러 **Script = 사랑의 주사위**, **When Interacting = Run Script**

이 폴더의 `widget/scriptable-ios.js` 가 같은 스크립트의 원본입니다
(맨 위 두 줄만 내 것으로 바꿔 쓰면 됩니다).

### ③ 아이폰 — 단축어로 아침 알림

**단축어 → 자동화 → 시각(오전 7:00, 매일, 즉시 실행)** →
`URL 콘텐츠 가져오기`(위젯 탭의 주소) → `사전 값 가져오기`(키 `text`) → `알림 표시`

### ④ 안드로이드 — 자동으로 바뀌는 위젯

Play 스토어의 **KWGT** 위젯에서 텍스트 수식에 아래 형태를 넣습니다.

```
$wg(…/exec?api=my&u=내기기번호, json, .text)$
```

`json` 은 「JSON 에서 골라 오기」, `.text` 는 「그중 문구만 꺼내기」라는 뜻입니다.
(`wg` 의 정식 문법은 `wg(주소, 필터, 파라미터)` 입니다. 필터를 빼거나 `txt` 로 두면
문구 대신 `{"ok":true,"date":…}` 같은 JSON 원문이 그대로 위젯에 찍힙니다.)

앱의 **위젯** 탭에 내 주소가 채워진 완성 수식이 나오니 **[수식 복사]** 를 눌러 쓰면 됩니다.
**Tasker** 를 쓴다면 HTTP Request 로 같은 주소를 읽어 `text` 값을 꺼내면 됩니다.
복잡하면 **①번 배경화면 방식**을 쓰세요.

### 위젯이 읽는 주소 (JSON)

| 주소 | 돌려주는 것 |
|---|---|
| `…/exec?api=my&u=<기기번호>` | 내가 오늘 정한 면 (아직 안 던졌으면 오늘의 공통 면) |
| `…/exec?api=today` | 날짜로 정해지는 오늘의 공통 면 (누구나 같은 값) |
| `…/exec?api=stat` | 오늘 참여자 수와 면별 분포 |

```json
{ "ok": true, "date": "2026-07-31", "face": 2,
  "text": "먼저 사랑하자", "short": "먼저 사랑하자", "mine": true }
```

`&callback=함수이름` 을 붙이면 JSONP 로도 받을 수 있습니다.

## 관리하는 사람을 위한 메뉴

스프레드시트 위쪽 **💜 사랑의 주사위** 메뉴

| 메뉴 | 하는 일 |
|---|---|
| 시트 준비하기 | 시트 3장을 만들고 머리글을 꾸민다 |
| 오늘 현황 보기 | 오늘 참여자 수·면별 분포·쌓인 글 수 |
| 신고된 글 보기 | 신고가 들어온 글 목록 |
| 고른 줄 숨기기 / 다시 보이기 | `경험담` 시트에서 줄을 고르고 누르면 보임 ↔ 숨김 |
| 나눔 받기 켜기 / 끄기 | 새 글 받기를 잠시 멈춘다 (읽기는 그대로) |

**자동 보호 장치**

- 같은 기기는 **30초에 한 편**, **하루 10편**까지
- 한 편 **500자**까지
- 거친 말이 들어가면 올라가지 않습니다
- **3명이 신고하면 자동으로 숨겨집니다**

## 개인정보

- **로그인이 없습니다.** 이름·이메일·전화번호를 받지 않습니다.
- 사람 구분은 폰이 처음 한 번 만든 **무작위 기기 번호(uid)** 하나뿐입니다.
  하트를 두 번 누르지 못하게 하고, 위젯이 내 주사위 결과를 보여 주는 데만 씁니다.
- 이름 칸은 **본인이 원할 때만** 쓰는 표시 이름입니다. 비우면 「익명」으로 올라갑니다.
- 글을 지울 때 쓰는 숫자 4자리는 **되돌릴 수 없게 뭉갠 값(SHA-256)** 으로만 저장돼
  관리자도 볼 수 없습니다.

## 배포하기 전에 혼자 확인하기

`index.html` 을 그냥 더블클릭해도 **미리보기 모드**로 열립니다.
3D 주사위·배경화면 만들기·글쓰기·하트가 모두 동작하며,
내용은 **그 컴퓨터에만** 저장되고 서버로는 가지 않습니다.
